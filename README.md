# Regen Commons community files

This repository maintains the [Regen Commons GitHub profile](profile/README.md) and shared contribution, support, and conduct guidance for repositories in the `regen-commons` organization.

For the Commons itself, start at [regencommons.com](https://regencommons.com/) or the [community forum](https://hub.regencoordination.xyz/c/regen-commons/33).

## What's here

| File | Purpose |
| --- | --- |
| [profile/README.md](profile/README.md) | Introduction displayed on the organization's GitHub profile |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Ways to contribute and prepare work for review |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Participation expectations and reporting concerns |
| [SUPPORT.md](SUPPORT.md) | Where to ask for help |
| [SECURITY.md](SECURITY.md) | Private vulnerability reporting guidance |
| [GOVERNANCE.md](GOVERNANCE.md) | How repository decisions relate to wider stewardship |
| [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE) | Bug, task, design, research, and proposal templates |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | A short change and validation summary |

GitHub uses [supported community files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) as defaults where a repository does not provide its own. A repository's own issue templates or chooser configuration replace the shared issue-template set. `GOVERNANCE.md` is linked guidance, not a GitHub-inherited community file. The [MIT license](LICENSE.md) applies to this repository; GitHub does not inherit licenses across repositories.

## Keeping this useful

- Keep the profile brief and link to project READMEs for current implementation status.
- Check wording against public community updates and the people responsible for the work. Keep proposals distinct from adopted decisions.
- Publish only material intended for public use. Collaborative drafts and private meeting notes belong in their existing shared spaces until cleared for publication.
- Verify contact and funding destinations before adding them. The inherited Dev Guild funding configuration has been removed; add `.github/FUNDING.yml` only when a Regen Commons receiving route is confirmed.
- Check local links, public destinations, template YAML, and the diff when updating these files. There is no application build or test suite in this repository.

The [October 2026 stewardship update](https://hub.regencoordination.xyz/t/update-from-the-stewardship-council-on-regen-commons-q4-2026/474) provides public context for the current focus. For proposed edits, open an issue or pull request here.
